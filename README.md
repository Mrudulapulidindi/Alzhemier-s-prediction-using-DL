##Alzheimer’s Disease Prediction using Machine Learning

This repository contains the complete implementation of an Alzheimer’s Disease Prediction system using machine learning. It includes the Python source code, the research paper, and the project presentation. The goal of this project is to detect Alzheimer’s at an early stage by analyzing MRI-based features and applying machine learning models for classification.

##Project Overview

The model focuses on preprocessing MRI data, extracting meaningful features, training multiple machine learning algorithms, and evaluating their performance. The project compares classifiers such as Logistic Regression, Random Forest, SVM, KNN, and others to determine the most effective model for prediction. The system generates accuracy scores, confusion matrices, and performance metrics that help identify how well the model detects Alzheimer’s in early stages.

##Repository Structure

src/alzheimer_prediction.py contains the main machine learning code.
research/research_paper.pdf contains the full research documentation.
presentation/project_presentation.pdf contains the project PPT.

##Results

The final model achieves strong performance based on accuracy, precision, recall, and F1-score. The comparison of machine learning models and result analysis is available in the research paper.

##Documentation

The research paper provides methodology, dataset information, algorithm selection, and complete evaluation details. The presentation offers a summarized visual explanation suitable for academic submission.
